# TradePilot PWA
This is the installable phone version of the Stage 1 paper-trading simulator.

## Use on Android
A PWA needs to be served from HTTPS (or localhost) for installation/service-worker support.
The easiest route is to upload these files to a static host such as GitHub Pages, Netlify, Vercel, or Cloudflare Pages, then open the HTTPS address in Chrome and choose "Install app" / "Add to Home screen".

## Important
This version is still paper trading only. It has no broker connection and does not place real orders.
